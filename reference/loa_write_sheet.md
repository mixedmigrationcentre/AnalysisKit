# Write One Sheet of the Workbook

Write One Sheet of the Workbook

## Usage

``` r
loa_write_sheet(wb, sheet, df, dropdown_rows)
```

## Arguments

- wb:

  An openxlsx workbook.

- sheet:

  The sheet's name.

- df:

  Its data.

- dropdown_rows:

  Number of data rows the drop-down lists cover.

## Value

`wb`, invisibly.
