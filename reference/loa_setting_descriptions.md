# What Each Setting Does

One plain sentence or two per key of
[`loa_settings_schema()`](https://mixedmigrationcentre.github.io/analysiskit/reference/loa_settings_schema.md),
written into the `description` column of the `settings` and
`route_analysis` sheets.

## Usage

``` r
loa_setting_descriptions()
```

## Value

A named character vector, one element per setting.
