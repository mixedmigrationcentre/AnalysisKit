# A Country or Place Answer That Names No Place

"None", "Refused", "Don't know" and the like. Such a slot is not a stop
or a dangerous location, so it is left out of the rankings and gets no
section.

## Usage

``` r
ck_route_place(x)
```

## Arguments

- x:

  Character vector from
  [`ck_route_text()`](https://mixedmigrationcentre.github.io/analysiskit/reference/ck_route_text.md).

## Value

The vector with non-answers set to `NA`.
