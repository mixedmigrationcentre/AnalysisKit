# Spread Slot Rows Onto Respondents

Spread Slot Rows Onto Respondents

## Usage

``` r
ck_route_expand(fu_long, id, ids)
```

## Arguments

- fu_long:

  Named list of slot-level 0/1/NA matrices.

- id:

  The respondent of each slot.

- ids:

  Every respondent.

## Value

The matrices pooled to one row per element of `ids`.
