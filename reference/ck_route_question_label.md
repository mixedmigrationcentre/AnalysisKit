# A Question's Label From the ONA Label Row

A Question's Label From the ONA Label Row

## Usage

``` r
ck_route_question_label(q, label_row, fallback = NULL)
```

## Arguments

- q:

  The question name.

- label_row:

  The label row, or `NULL`.

- fallback:

  Used when the label row has no text for `q`.

## Value

A single string.
